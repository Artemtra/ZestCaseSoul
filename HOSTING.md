# Хостинг zestcasesoul.ru

Домен `zestcasesoul.ru` уже прописан в проекте как публичный адрес:

```env
APP_URL=https://zestcasesoul.ru
```

Сам домен не хранит сайт. Нужно, чтобы DNS домена указывал на сервер, где запущен проект.

## Вариант 1. VPS/сервер

1. Арендуй VPS с публичным IPv4.
2. На VPS установи Node.js, MariaDB и скопируй проект.
3. В панели домена создай DNS-записи:

```text
A     @      IP_ТВОЕГО_VPS
A     www    IP_ТВОЕГО_VPS
```

4. На сервере запусти:

```bash
npm install
npm run migrate
npm start
```

5. Чтобы сайт открывался как `https://zestcasesoul.ru/`, настрой reverse proxy с порта `80` на Node-порт `3000`.

## Вариант 2. Домашний ПК

1. Узнай свой внешний IPv4.
2. В панели домена создай DNS-записи:

```text
A     @      ТВОЙ_ВНЕШНИЙ_IP
A     www    ТВОЙ_ВНЕШНИЙ_IP
```

3. В роутере сделай проброс:

```text
external 80 -> твой_локальный_IP:3000
```

4. Запусти `start.bat`.

Если провайдер использует CGNAT, домен напрямую на домашний ПК не заработает. Тогда нужен VPS или туннель с привязкой своего домена.
